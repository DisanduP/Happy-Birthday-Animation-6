# Happy-Birthday-Animation-6

A small, lightweight Happy Birthday animation built with plain HTML, CSS and JavaScript — perfect for sending a quick animated greeting or embedding in a webpage.

## Demo

![Animation screenshot](./Screenshot%202025-10-22%20at%2017.25.00.png)

> Open `index.html` in any modern browser to see the animation.

## Features

- Pure HTML/CSS/JavaScript (no frameworks or build tools)
- Single-page, easy to customize
- Smooth CSS animations and JavaScript timing
- Works offline — just open the file in your browser

## Quick Start

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Happy-Birthday-Animation-6.git

2. Open `index.html` in your browser:

   - Double-click the file, or
   - Serve the folder with a simple static server (optional):

     npx http-server .

3. Enjoy the animation!

## Customization

- Change the displayed text in `index.html`.
- Tweak colors, sizes, and animation timing in the stylesheet (usually `style.css` or inside `index.html`).
- Modify or extend the JavaScript to add more interactivity or sequencing.

## Deployment

This project can be hosted on any static hosting provider (GitHub Pages, Netlify, Vercel) — just publish the repository root.
